# A.T.L.A.S. Control Center 0.4.2 — Patch notes

- Accelerometer calibration now shows the initial gyro calibration phase, incoming COMMAND_ACK outcomes and MAV_CMD_ACCELCAL_VEHICLE_POS step messages, including diagnostic timeout when no first position arrives. Local Close Wizard does not send a fictitious cancel command to the autopilot. If the vehicle has not answered after timeout, investigate its MAVLink messages before restarting.
- MAVLink STATUSTEXT decoding fixed to use up to 50 bytes instead of 16, so ArduPlane diagnostic messages are no longer truncated at the parameter-name length.
- Mission Planner-inspired parameter group selector: preserves ALL, while categorizing parameters by known names/prefixes. This is a convenient heuristic, not the official ArduPilot metadata hierarchy.
- Import .param, compare values, and write all CHANGED, KNOWN parameters sequentially over MAVLink PARAM_SET. Each write waits for matching PARAM_VALUE readback, with up to three attempts, and reports success and failures. Unknown parameters are clearly skipped, rather than guessed. No artificial denylist of existing parameter families. A fresh DISARMED heartbeat, explicit review and backup confirmation, and stable USB connection are retained.
- RU/UA/EN translations for Servo Output, Battery Monitor and Compass labels; existing calibration descriptions remain multilingual.
- DFU code and included Matek H743 V3 HEX left unchanged from previous release.

## Tests / limitations

JavaScript syntax and archive integrity validated, plus static protocol review. No physical Matek FC is attached; neither accel 6-position run nor write of parameter files can be declared hardware-validated. Systematically perform initial tests on bench with propeller removed. Recording live MAVLink traffic/console events helps resolve further missing position requests.

This package includes the publicly distributable user-supplied HEX; distributing modified ArduPilot binaries requires providing the corresponding source and GPL notices.
