# A.T.L.A.S. Control Center v0.5.0 — release notes

## Website and translations
- Added Changelog navigation to home and configurator sidebar.
- Added `changelog.html`, `changelog.js`, `changelog.css`, `data/changelog.json` with **16 documented development areas** in RU / UK / EN.
- Each changelog item has an evidence class: current retained snippet, earlier-branch source, development history, or experimental/unverified.
- Added `config-ui-i18n.js`: 109 additional static UI strings translated to Ukrainian and English. Existing Russian labels remain available.
- Improved Russian/Ukrainian naming in Advanced Tuning and translated frequently used labels in grouped tuning widgets.
- Kept Oleksandr × AI CODEX credits and existing three-language selector.

## Performance and resilience
- Main-page interactive model now pauses heavy animation outside the viewport or when the tab is hidden; capped near 30 FPS.
- Dashboard canvas rendering is reduced when inactive and capped near 30 FPS.
- Heavy Parameter List/Basic grid rebuilds are skipped when those tabs are inactive; streaming batch updates throttled.
- Gamepad polling slowed and suppressed in background tabs.
- Restored dashboard animation safely on browser back-forward cache return without claiming the USB session is still open.
- Better mobile horizontal sidebar scrolling, touch targets and narrower layouts.

## Checks and limits
- Retained working 6-position accelerometer protocol fix, DFU flashing gate, Servo Output, OSD, MAVFTP and other features.
- The current working directory does not include the complete firmware 4.7.2 source tree or upstream matching tag, therefore **the firmware changelog is not a complete proven diff**.
- No real Matek/ESC hardware tests were executed for this revision. Static JavaScript and site-file checks are included, but browser UI testing was limited by the runtime access policy.
- ROM DFU Mass Erase and firmware flashing have not been independently validated on physical hardware. Do not treat this as flight-certified or universally compatible firmware.
- The public HEX requires the corresponding modified ArduPilot source under the applicable GPL terms when redistributed.
