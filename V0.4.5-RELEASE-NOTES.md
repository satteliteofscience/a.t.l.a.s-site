# A.T.L.A.S. Control Center v0.4.5 — Servo Output live controls

- Added opt-in real-time PARAM_SET writes for SERVOx_REVERSED and SERVOx_MIN/TRIM/MAX. Changes wait for the echoed PARAM_VALUE; there is no automatic reconfiguration on editor open.
- Added an explicitly enabled, disarmed, time-limited 30-second PWM Bench Test slider. Uses MAV_CMD_DO_SET_SERVO only for SERVOx_FUNCTION = 0, 1, 51–66 or 140–155.
- No automatic servo FUNCTION reassignment, no motor/throttle override on FUNCTION 70. UI reports unsupported direct output instead of falsely claiming PWM was applied.
- Stop (best effort) sends 1000 µs. **Loss of USB, site crash, or loss of power may prevent the stop command; physical power must be removed to make an ESC safe**. No propulsion or motor testing with an installed propeller.
- Regular `SERVOx_*` changes can affect active physical outputs even in DISARMED state. Test on a bench with propeller removed.
- Existing six-position calibration, DFU firmware, languages and Parameter Tree retained.

## Verification
Automated JS syntax checks and UI tests performed. Cannot verify physical servo PWM output, command ACK response, or ESC calibration behavior without a real controller. Verify output separately via SERVOn/oscilloscope or SERVO_OUTPUT_RAW and do not consider a sent command proof of physical movement.
