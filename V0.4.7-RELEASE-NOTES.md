# A.T.L.A.S. Control Center v0.4.7 — Extended Setup

This release integrates seven Mission Planner-inspired panels into the existing **0.4.6** GitHub Pages website. It is **not** the standalone 0.4.7 UI mockup.

## Added panels

| Panel | Current implementation | Commands and data |
|---|---|---|
| Basic Tuning | Numeric +/- controls for real Roll/Pitch/Yaw PID, L1, TECS, throttle, navigation angles and airspeed parameters | Read from `PARAM_VALUE`; changes sent via individually acknowledged `PARAM_SET` after confirmation |
| Flight Modes | Six flight modes, switch-channel PWM / active-position display | `FLTMODE1..6`, `FLTMODE_CH`, `RC_CHANNELS`; writes acknowledged `PARAM_SET` |
| Radio Calibration | Live 16-channel PWM readouts, user-started min/max capture and centered trim sampling | `RC_CHANNELS`, `RCx_MIN`, `RCx_TRIM`, `RCx_MAX`; writes require user confirmation |
| MAVFTP | Directory navigation and downloading files, 12 MiB browser cap | Read-only MAVFTP opcodes `ListDirectory`, `OpenFileRO`, `ReadFile`, `TerminateSession`; no write/delete |
| Joystick | Browser Gamepad API axis/button preview and local axis assignment | **No RC override or flight-control commands** |
| Camera Gimbal | Forms for parameters discovered on the vehicle | `MNT1_*`, `CAM1_TYPE`, acknowledged `PARAM_SET` |
| Parachute | Editable configuration if these parameters exist | `CHUTE_*` values only; **no deploy command** |

## Reused without removing

- GitHub Pages main website and multilingual theme
- WebUSB STM32 DFU + Matek H743-WING V3 HEX
- Parameter Tree, .param backup/import, basic setup
- Existing 6-position accelerometer and compass calibration logic
- Existing 16-channel Servo Output and OSD editor

## Safety and limits

- This is an **experimental** web tool. No real-hardware regression test of the seven new panels has yet been performed.
- All multi-parameter edits require a live DISARMED heartbeat, no concurrent parameter transfer and a user confirmation checkbox. Writes are serialized and checked against returned `PARAM_VALUE` values; a partial failure is reported.
- Radio calibration uses RC input samples received during the capture interval; keep sticks centered when finalizing trim. It is not an automatic ArduPilot radio-calibration wizard.
- MAVFTP read operations are implemented using the standard command format, but haven't been tested against a physical FC in this release.
- Joystick is **display-only**; no aircraft control from browser joystick.
- Parachute configuration does **not** deploy parachute.
- Some setting changes require FC reboot; do not test with the propeller installed.
- The supplied HEX is distributed in `Firmware/Matek Wing H743-V3`; do not put the archive in a private repo expecting the HEX to remain private if GitHub Pages is public. Preserve GPL license/source availability requirements for redistributed ArduPilot derivatives.

## Deployment

Unzip all contents into the root of the public GitHub Pages repository (where `index.html` lives), replacing previous site files. Choose `Settings → Pages → Deploy from a branch → main /(root)`. The configurator is accessible at `configurator.html`.
