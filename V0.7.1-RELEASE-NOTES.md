# A.T.L.A.S. Control Center 0.7.1 — localization improvements

- Main browser-tab title and description now follow the selected **Русский / Українська / English** locale.
- Browser-tab titles, descriptions and Open Graph metadata are localized on Home, Configurator, FAQ, Changelog and Privacy pages.
- The static metadata fallbacks are Russian for browsers without JavaScript; dynamic metadata follows the language selector. Messaging/social bots may use static metadata without running JavaScript.
- Added missing Russian live HUD strings: HOVER TO CONTROL, FLIGHT CONTROL and BOOST ACTIVE, and translated aircraft-demo labels for RU/UA/EN.
- No flight-controller algorithms, DFU, firmware binaries, subscriber API or payment configuration were altered.
- Subscription setup remains documented in MAIL-SERVICE-SETUP.md and the private ATLAS-Subscriber-Service-v0.7.0 package; HTTPS and SMTP need to be configured before registration can work.
