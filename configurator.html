Скачай один файл для Windows и открой двойным щелчком. Он запустит локальный коннектор, откроет сайт и подключит TCP автоматически — без ручного ввода токена. На первом запуске может понадобиться загрузка проверенной портативной версии Node.js.

Скачать TCP Connector для Windows

Нужно разрешить доступ к локальному устройству в браузере. Не закрывай окно коннектора во время работы. Если TCP-сервер допускает только одного клиента, отключи Mission Planner перед подключением.

Ручные настройки UDP/TCP и других адресов

GitHub Pages не открывает UDP/TCP напрямую. Запусти на ПК: node tools/mavlink-bridge.cjs. Мост требует токен и соединяется по WebSocket. UDP/TCP используют только в доверенной сети/VPN.

    05 / FLIGHT CONTROLLER CALIBRATION

    Акселерометр

    USB / DISARM REQUIRED

    Калибровка акселерометра ArduPlane через MAVLink. Отключи моторы и сними пропеллер. Сначала проверь ориентацию контроллера AHRS_ORIENTATION.

    ◎Простая калибровкаMAV_CMD 241 · P5=4

    Положи самолёт горизонтально и неподвижно. Калибрует смещения акселерометра, но не полную геометрию по шести осям.

    ⎔Полная 6-позиционнаяMAV_CMD 241 · P5=1

    Автопилот сам запрашивает положение. Установи аппарат в нужную позицию, дождись неподвижности и нажми подтверждение.

    ━Установить горизонтMAV_CMD 241 · P5=2

    После калибровки акселерометра установи самолёт в положение горизонтального полёта и откалибруй уровень. Коррекция ограничена.

    08 / MAGNETOMETER

    Компас

    DISARM REQUIRED

    Настройка компаса и калибровка вращением аппарата. На самолётах без GPS компас может быть выключен — в этом случае запускай калибровку только если он действительно установлен и используется.

    ⌖Калибровка магнитометраMAV_CMD 42424–42426

    Повертай аппарат вокруг всех осей. При неудачной попытке автопилот автоматически повторит сбор данных, а успешный результат сохранит.

    Меньший порог — более строгая проверка, а не гарантированно более быстрая калибровка. Режим сохраняется в COMPASS_CAL_FIT только после подтверждения записи полётником.

    NO DATA0%

    IDLE

    ⌘Параметры компасаCOMPASS_*

    Не включай компас принудительно только ради этого раздела. При отключённом датчике калибровка может быть отклонена автопилотом.

    DFU-подключение (не MAVLink)

    Удерживай кнопку BOOT на USB-переходнике Matek и подключи USB к ПК, затем нажми «Подключить DFU». Закрой Mission Planner и другие программы, использующие этот USB-порт.

    DFU не подключён
    Файл не загружен
    DFU · 0%

    Загрузка прошивки — только по команде пользователя

    После успешной записи дождись полной загрузки контроллера. Если COM-порт не появился, отключи и подключи USB ещё два раза. На Matek H743-WING V3 он может определиться только при третьем подключении.

    ВНИМАНИЕ: полный Mass Erase 2 MiB (до 0xFF), затем запись и побайтовая проверка. При обрыве питания понадобится восстановление через DFU/STM32CubeProgrammer. Проверено только на уровне кода, не на физической плате.

    SERVO OUTPUT / CHANNEL

    ⚠ Включи «Применять сразу», иначе переключение реверса изменяет только черновик. FUNCTION=70 не поддерживает ручную установку PWM через DO_SET_SERVO.

    Дополнительно: ручной PWM-тест
    PWM BENCH TEST / Ручной PWM—

    Прямая команда PWM доступна лишь для выхода FUNCTION=0/1 или RC Passthrough. Она не заменяет изменение SERVOx_MIN/MAX/REVERSED.

    SERVO_OUTPUT_RAW: —

    Тест не активен. При потере связи принудительный PWM может сохраняться на контроллере — отключи питание ESC.

    Проверь правильность FUNCTION, MIN, TRIM, MAX и REVERSED. Изменения могут сразу влиять на активные выходы. Сними пропеллер.
