# A.T.L.A.S. 4.7.2 — предварительная карта модификаций

Этот список не является полным подтверждённым diff с upstream ArduPlane 4.7.2. Он основан на сохранённом исходнике `mode_fbwa.cpp`, архивном changelog 4.7.1 и истории обсуждений. Перед публичным заявлением о конкретном патче необходимо сравнить исходники реально собранного HEX с чистым тегом 4.7.2.

## ATL-001 EKF3 NOAID — оценка ориентации без GPS
Статус основания: `history`. Категория: `ekf`.

Изменения ветки EKF3 для AID_NONE без спутниковой навигации: работа с воздушной скоростью, управление корректировкой состояния и подавление ложных оценок скорости до начала полёта.

## ATL-002 Псевдоскорость и Пито после определения запуска
Статус основания: `history`. Категория: `ekf`.

По истории испытаний синтез горизонтальной скорости из TAS и ориентации активируется после реального старта; продувка Пито на земле не должна создавать нарастающий GSPD.

## ATL-003 Численная устойчивость EKF3
Статус основания: `history`. Категория: `ekf`.

Обсуждались обновление ковариации в форме Джозефа, корректировка шума наблюдений в манёврах и особенности замораживания акселерометрического смещения при NOAID. Точные флаги и параметры требуют сверки с релизной сборкой.

## ATL-004 TAKEOFF без GPS и HOME
Статус основания: `excerpt`. Категория: `flight`.

В сохранённом mode_takeoff.cpp версии 4.7.1 есть отдельная ветка запуска с барометрической высотой, удержанием курса по AHRS и переходом в CIRCLE после набора высоты. Вхождение именно этой реализации в 4.7.2 ещё не сверено.

## ATL-005 Разблокировка газа при повторном TAKEOFF
Статус основания: `excerpt`. Категория: `flight`.

В сохранённом servos.cpp движение может подтверждаться EAS от Пито (порог 5 м/с) вместе с признаками полёта, высоты и тангажа. Это не отключает защиту газа безусловно.

## ATL-006 Изменения CRUISE без GPS
Статус основания: `excerpt`. Категория: `flight`.

В сохранённом mode_cruise_v7.cpp описаны захват курса и высоты по AHRS/барометру, ручной перехват элеронами и рулём высоты, а также ограничения по приближению к скорости сваливания.

## ATL-007 Экспериментальная автопосадка без GPS
Статус основания: `experimental`. Категория: `flight`.

В истории A.T.L.A.S. есть отдельные правки автопосадки без GPS. Поскольку абсолютной координаты без внешнего источника нет, точность захода и безопасная посадка требуют проверки алгоритма, датчиков и SITL/лётных испытаний.

## ATL-008 Failsafe: переходы между режимами
Статус основания: `history`. Категория: `safety`.

По истории разработки дорабатывалась последовательность потери связи, включая TAKEOFF → CIRCLE → RTL. Условия применения и поведение при отсутствии HOME необходимо сверить по реальному коду.

## ATL-009 FBWA: RUD_LIMIT_DEG и дополнительный крен
Статус основания: `snippet`. Категория: `control`.

В сохранённом mode_fbwa.cpp рудер по направлению крена может добавлять команду крена через RUD_LIMIT_DEG с ограничением запаса до 85°. Старая настройка RUD_RLL_ADD в актуальной логике не используется.

## ATL-010 FBWA: адаптивное ограничение руля направления
Статус основания: `history`. Категория: `control`.

Согласно обсуждавшейся реализации limit_manual_rudder, влияние ручного руля направления смягчается вблизи допустимого крена с учётом крена, скорости вращения и воздушной скорости. Текущие коэффициенты требуют дифф-сверки.

## ATL-011 Дополнительная проверка RC3 перед ARM
Статус основания: `history`. Категория: `safety`.

История проекта описывает запрет армирования при небезопасном положении газа на RC3. Конкретные пороги и охват путей армирования не подтверждены в текущей сборке.

## ATL-012 Звуковые уведомления A.T.L.A.S.
Статус основания: `history`. Категория: `hardware`.

Обсуждалась собственная звуковая индикация загрузки, начала и завершения калибровок и системных событий. Набор сигналов и поддерживаемое оборудование требуют проверки.

## ATL-013 BLHeli32 / ESC и телеметрия
Статус основания: `history`. Категория: `hardware`.

По истории работы изменялись разбор потока BLHeli32, обработка CRC и взаимодействие с ESC. Это не означает универсальную поддержку любого регулятора; телеметрия и управление — разные механизмы.

## ATL-014 RC/VTX: управление видеопередатчиком
Статус основания: `experimental`. Категория: `hardware`.

В предыдущих ветках обсуждалось переключение каналов VTX через RC/Lua и изменения VideoTX. Включение этой функции в последнюю 4.7.2 HEX пока не подтверждено.

## ATL-015 Диагностика CPU / RAM / частоты цикла
Статус основания: `excerpt`. Категория: `hardware`.

В сохранённом Plane.cpp версии 4.7.1 присутствовала периодическая строка о частоте MCU, частоте основного цикла, загрузке процессора и свободной RAM. Индикация частоты сама по себе не разгоняет процессор.

## ATL-016 Сборки под Matek H743-WING V3
Статус основания: `history`. Категория: `hardware`.

На сайте опубликован Intel HEX для STM32H743 с пометкой 480 MHz. Совместимость определяется фактическим hwdef/target и проверкой платы; название файла не является доказательством всех изменений прошивки.

## Что не считается изменением исходников

Параметры `INS_TCAL`, `ARMING_SKIPCHK` и другие настройки относятся к конфигурации до тех пор, пока изменение исходного кода не доказано. Отдельно не следует путать новые возможности веб-конфигуратора с кодом прошивки самолёта.
