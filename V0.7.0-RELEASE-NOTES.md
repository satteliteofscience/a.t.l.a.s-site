# A.T.L.A.S. Control Center 0.7.0

- Configured user-supplied IBAN for manual donation bank transfer (valid UA checksum).
- Added optional double-opt-in email signup UI with flight-controller preference, language and optional early-testing interest.
- Added explicit option to donate without newsletter subscription.
- Added a separately deployable private SMTP/SQLite subscriber backend (packaged outside the public site), with confirmation, unsubscribe, rate limiting, admin approval and matching firmware attachments.
- Added privacy notice, upgraded repository README, GitHub About template, social-preview image, suggested commit messages, and deployment instructions.

**Deployment blockers:** public subscription API endpoint, server, SMTP credentials and operator contact have not been provided. Automatic email delivery and payment confirmation are not activated. IBAN transfers are handled by users' banks, outside the website. Early-test eligibility is never granted solely by submitting an email or by a claimed transfer.
