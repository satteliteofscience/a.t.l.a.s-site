# A.T.L.A.S. — BlockBlueprint visual trial

Этот вариант использует растровые изображения заголовков, созданные из вашего шрифта BlockBlueprint, без вложения файла шрифта в сайт. Основной русский текст оставлен IBM Plex Sans для читаемости.

В ZIP находятся исходники сайта для предварительного просмотра. Для локального просмотра откройте `index.html`. Отдельная страница `preview.html` с макетом удалена из репозитория, она остаётся в истории git.

**Лицензия:** предоставленный BlockBlueprint помечен как демонстрационный / Free for Personal Use. Перед публичным размещением, особенно с коммерческим использованием или раздачей webfont, получите разрешение правообладателя (HipFonts). Даже растровые изображения следует считать экспериментальным макетом до подтверждения прав использования.
