# A.T.L.A.S. Control Center v0.4.3

## Fixed
- MAVLink 2 COMMAND_LONG messages can omit trailing three zero bytes. The previous check `payload.length >= 33` discarded valid 30-byte `MAV_CMD_ACCELCAL_VEHICLE_POS` requests (42429). Now requires >=30 and handles omitted target/confirmation as zero.
- MAVLink 2 STATUSTEXT shorter than the nominal 51-byte payload is now parsed correctly.
- Accelerometer wizard reports received valid frames, CRC failures, COMMAND_LONG, pose requests, ACK and text counts. Diagnostic JSON copy/export is available.

## Parameter tree
- Expandable group and parameter tree by actual names loaded from the flight controller.
- Seven columns: Name, Value, Default, Units, Options, Desc, Fav. Responsive mobile tree and horizontally scrollable table.
- Partial metadata bundle from supplied A.T.L.A.S. Parameters.cpp comments; optional load of official ArduPlane pdef XML/JSON in browser. Unknown defaults and descriptions are intentionally left blank, not invented.
- Existing `.param` import, batch write, export and incomplete-list retry retained.

## Verification
- JS syntax checks and simulated MAVLink2 truncated 30-byte accel position protocol.
- NOT yet validated against physical Matek FC.
